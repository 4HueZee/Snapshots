# Holistic Language & IP Assessment: Tabletop Crossover

This document provides a breakdown of language used in sci-fi/fantasy tabletop environments, distinguishing between trademarked/IP-held terms and "Safe Harbor" (generic or open-use) language. 

## 1. The "Safe Harbor" Principle
Language qualifies as Safe Harbor if it meets one of these criteria:
- **Historical/Latin Roots**: Words derived from Latin or Greek that describe common concepts (e.g., *Vox*, *Astra*, *Terra*).
- **Generic Sci-Fi/Fantasy Tropes**: Concepts that are established industry standards (e.g., *Warp Drive*, *Orcs*, *Elves*, *Power Armor*).
- **Descriptive Functionalism**: Terms that describe what a thing *is* or *does* without brand-specific flavor (e.g., *Assault Carrier*, *Data Terminal*).

## 3. Ideal Crossover Findings for "Battle Barge"

To maintain the tabletop "feel" while staying legally insulated, the following linguistic pillars are recommended:

### Pillar 1: High-Gothic / Latinate
Use Latin-inspired words that feel ancient and authoritative.
- **Astra / Astral** (Stars)
- **Prime / Primus** (First/Superior)
- **Vigil / Vigilant** (Guardians)
- **Sanctum** (Safe area)

### Pillar 2: Generic Brutalism
Use heavy, descriptive nouns that imply weight and industrial sci-fi.
- **Foundry** (Instead of Manufactorum)
- **The Grinder / Frontline** (Instead of Kill Zone)
- **Ironclad / Heavy Plate** (Instead of specific armor names)

### Pillar 3: User-Defined Labels (The UGC Loophole)
As we've implemented in the Profile Settings, the safest harbor is **User-Generated Content**. 
- You provide the field: `Operational Sector`. 
- The user provides the IP: `Segmentum Solar`. 
- **Legal Result**: You are a neutral service provider; the user is responsible for the content.
